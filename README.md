# wc-images

Public image assets for the World Cup stories Facebook page.

Served via GitHub Pages at:
    https://shehan011.github.io/wc-images/

URL pattern:
    https://shehan011.github.io/wc-images/photos/{player_id}.jpg
    https://shehan011.github.io/wc-images/crests/{team_id}.png
    https://shehan011.github.io/wc-images/tournament logos/world-cup-{year}-logo.png

Player photos sourced from SofaScore. Tournament logos are FIFA-owned.
This repository hosts them for the renderer's image-fetch step; it is not
intended for general use.
